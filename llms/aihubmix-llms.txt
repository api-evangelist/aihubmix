# AIHubMix

## 文档

### 开始使用

- [产品介绍](https://docs.aihubmix.com/cn/index.md): 了解 AIHubMix 的模型调用、兼容接口和按量计费，查找模型选择、控制台、企业协作与通知使用指南。
- [快速开始](https://docs.aihubmix.com/cn/quick-start.md): 生成 API 密钥并进行首次调用
- [选择模型](https://docs.aihubmix.com/cn/guides/choose-models.md): 在模型广场按任务、输入类型、能力和价格缩小候选范围，使用列表、表格与收藏整理模型，再进入详情比较或试用。
- [智能搜索](https://docs.aihubmix.com/cn/guides/smart-search.md): 用自然语言描述任务，在模型广场寻找符合输入、能力和成本要求的候选模型，了解匹配分，并在无结果或搜索失败时调整条件。
- [模型详情与比较](https://docs.aihubmix.com/cn/guides/model-details.md): 读懂模型的输入输出、上下文、性能和计价单位，确认版本与模型 ID，在相同任务下比较候选并选择接入方式。
- [Skills](https://docs.aihubmix.com/cn/skills.md): AIHubMix Skill 为 Codex、Claude Code、Cursor、Cline 等 AI Agent 提供实时模型查询、接入配置、调用示例生成与错误排查能力。
- [Agent 接入](https://docs.aihubmix.com/cn/agents.md): AIHubMix 面向 AI Agent 的全部接入入口：agents.md 接入说明、llms.txt 机读索引、每模型 llms.txt 调用指南、Playground Skill、Playground 深链。每项一条可复制命令。
- [零数据存储说明](https://docs.aihubmix.com/cn/api/Data-Pravicy.md)
- [常见问题](https://docs.aihubmix.com/cn/FAQs/Faq.md): 高频问题请先查阅此文档
- [HTTP 状态码](https://docs.aihubmix.com/cn/FAQs/HTTP-Codes.md): 关键错误代码映射表
- [Status](https://docs.aihubmix.com/cn/api/Status.md)
- [提交反馈](https://docs.aihubmix.com/cn/FAQs/Feedback.md): 遇到问题时，可以通过工单表单向我们提交反馈，附上 Tid 可以帮助我们更快定位问题。

### 控制台使用

- [控制台概览](https://docs.aihubmix.com/cn/console/overview.md): 从控制台管理 API Key、查看用量与请求日志、充值和设置通知，了解账户与工作区范围，并快速找到常用功能入口。
- [API Key 管理](https://docs.aihubmix.com/cn/console/api-keys.md): 创建并管理模型调用凭证，配置模型范围与额度，使用映射和回退等高级功能，并安全完成停用、替换与删除。
- [用量看板](https://docs.aihubmix.com/cn/console/usage.md): 按账户、工作区和时间范围查看调用与消费趋势，理解费用、请求和 token 指标，并从汇总数据进入请求日志定位问题。
- [请求日志与排查](https://docs.aihubmix.com/cn/console/request-logs.md): 通过时间、模型、Key 和状态定位调用，查看 token、费用与耗时，配置日志表格并导出记录，使用 Tid 向支持团队反馈问题。
- [余额与账单](https://docs.aihubmix.com/cn/console/billing.md): 充值并核对到账，设置自动充值和低余额提醒，查看交易与发票，并了解企业共享余额、支付处理中和账户切换的规则。
- [消息中心](https://docs.aihubmix.com/cn/console/inbox.md): 通过消息中心查看模型动态、产品更新和账户通知，理解提示点与已查看状态，并从消息中的入口处理需要关注的问题。
- [通知设置](https://docs.aihubmix.com/cn/console/notifications.md): 设置低余额、模型上线、下线和调价提醒，选择网页、邮件或 Webhook 接收方式，并了解保存、关闭与必要账户通知的规则。
- [Webhook 通知接收设置](https://docs.aihubmix.com/cn/console/notification-webhooks.md): 把通知发送到飞书、Slack、Discord、Teams 或自有服务，了解目的地配置、签名、规则绑定、暂停与常见投递问题。

### 网关能力

- [统一推理参数](https://docs.aihubmix.com/cn/api/unified-inference.md)
- [模型映射与回退](https://docs.aihubmix.com/cn/api/Model-Mapping-Fallback.md): 在 AIHubMix 控制台为每个 API Key 配置模型名映射与错误时回退：把客户端的模型别名改写为真实上游模型，主模型失败时自动切换到备用模型，按最终响应模型计费，客户端代码零改动。
- [模型智能路由](https://docs.aihubmix.com/cn/api/llm-router.md): AIHubMix 智能路由：把模型名填 auto，网关按请求内容自动选出最优模型，支持成本优先 / 质量优先 / 低延迟策略，按实际命中模型计费，客户端代码零改动。
- [结构化输出修复](https://docs.aihubmix.com/cn/api/structured-output-repair.md): 为 API Key 开启结构化输出修复：结构化输出请求返回的 JSON 存在截断、尾随逗号、代码块包裹等格式错误时，网关自动修复为可解析的合法 JSON，数值保持原样，支持 Chat Completions、Responses、Claude、Gemini，客户端零改动。
- [异步任务](https://docs.aihubmix.com/cn/api/async-tasks.md): AIHubMix 图片、视频与统一任务协议：创建媒体任务、查询状态、下载结果、接收 Webhook，以及恢复中断后的 LLM 响应。
- [Broadcast](https://docs.aihubmix.com/cn/api/Broadcast.md): Broadcast 将 AIHubMix API 请求的 Trace 发送到外部可观测性平台，支持配置 LangWatch 目的地、隐私模式、采样率和 API Key 范围。

- [图像理解](https://docs.aihubmix.com/cn/api/vision.md): 了解如何使用视觉功能来理解图像。

- [TTS 文本转语音](https://docs.aihubmix.com/cn/api/TTS.md): 使用 AI 模型将文本转换为自然语音，支持多种语音风格和输出格式

- [实时对话](https://docs.aihubmix.com/cn/api/realtime-conversation.md): 通过 WebSocket 建立持久连接，与语音对话模型进行低延迟的双向语音／文本交互
- [向量嵌入](https://docs.aihubmix.com/cn/api/EBD.md): AIHubMix 提供兼容 OpenAI 标准的高效向量嵌入方案
- [重排序](https://docs.aihubmix.com/cn/api/Rerank.md): 通过 AIHubMix 的 /v1/rerank 接口调用 Jina、Cohere、Qwen 等重排模型，包含调用示例、请求参数、top_n 取值说明与可用模型列表。
- [FIM 补全](https://docs.aihubmix.com/cn/api/FIM.md)
- [结构化输出](https://docs.aihubmix.com/cn/api/Structured-Output.md): 通过 JSON Schema 约束模型输出格式（Structured Outputs），支持 OpenAI、Anthropic Claude、Gemini 等模型的 response_format 与 output_config.format，含自动降级与跨协议转换。
- [内容审查接口](https://docs.aihubmix.com/cn/api/moderation.md): 提供与 OpenAI 标准完全兼容的内容审查 API，开发者可以通过此接口，利用多模态审核模型自动识别文本或图片中的有害内容（如仇恨言论、暴力、违禁活动等），确保应用合规性。

#### AIHubMix Unified API

- [Create an AIHubMix image generation](https://docs.aihubmix.com/cn/api-reference/aihubmix-unified-api/create-an-aihubmix-image-generation.md): Generates images with the AIHubMix native media protocol. Requests are synchronous by default and become asynchronous when `async` is `true`.
- [List AIHubMix image tasks](https://docs.aihubmix.com/cn/api-reference/aihubmix-unified-api/list-aihubmix-image-tasks.md): Returns snapshots of image tasks created by the current API key.
- [Get an AIHubMix image task](https://docs.aihubmix.com/cn/api-reference/aihubmix-unified-api/get-an-aihubmix-image-task.md): Returns the latest state of an image task. Poll this endpoint for asynchronous image generation.
- [Download an AIHubMix image result](https://docs.aihubmix.com/cn/api-reference/aihubmix-unified-api/download-an-aihubmix-image-result.md): Downloads one result from a completed image task. Clients normally use the `output[].content_url` returned by the task object.
- [List AIHubMix video tasks](https://docs.aihubmix.com/cn/api-reference/aihubmix-unified-api/list-aihubmix-video-tasks.md): Returns snapshots of video tasks created by the current API key.
- [Create an AIHubMix video task](https://docs.aihubmix.com/cn/api-reference/aihubmix-unified-api/create-an-aihubmix-video-task.md): Creates a video task with the AIHubMix native media protocol. Video generation is always asynchronous.
- [Get an AIHubMix video task](https://docs.aihubmix.com/cn/api-reference/aihubmix-unified-api/get-an-aihubmix-video-task.md): Returns the latest state of a video task. Poll this endpoint until the task reaches a terminal state.
- [Download an AIHubMix video](https://docs.aihubmix.com/cn/api-reference/aihubmix-unified-api/download-an-aihubmix-video.md): Downloads the primary video result from a completed video task.
- [List unified AIHubMix tasks](https://docs.aihubmix.com/cn/api-reference/aihubmix-unified-api/list-unified-aihubmix-tasks.md): Returns read-only snapshots of image, video, and recoverable LLM tasks created by the current API key.
- [Get a unified AIHubMix task](https://docs.aihubmix.com/cn/api-reference/aihubmix-unified-api/get-a-unified-aihubmix-task.md): Returns a read-only task snapshot. Poll active media through the image or video detail endpoint instead.
- [Get the primary unified task result](https://docs.aihubmix.com/cn/api-reference/aihubmix-unified-api/get-the-primary-unified-task-result.md): Downloads a single media artifact or returns an archived LLM response. Multi-result tasks require the result-specific endpoint.
- [Get a specific unified task result](https://docs.aihubmix.com/cn/api-reference/aihubmix-unified-api/get-a-specific-unified-task-result.md): Downloads one result from a task with multiple artifacts.
- [List models with media request Schemas](https://docs.aihubmix.com/cn/api-reference/aihubmix-unified-api/list-models-with-media-request-schemas.md): Lists image or video models from the public model directory. Use `schema_checked=true` to return models whose request Schema has been reviewed.
- [Get a model's supported endpoints and request Schemas](https://docs.aihubmix.com/cn/api-reference/aihubmix-unified-api/get-a-models-supported-endpoints-and-request-schemas.md): Returns all currently discoverable protocol endpoints for a media model.
